# python-java-mini-projects
mini Python and java projects to practice and sharpen core programming concepts.

## Projects

### 1. To-Do List Manager(python)
A menu-driven command-line to-do list built using core Python fundamentals — no external libraries.

**Features:**
- Add a task
- View all tasks
- Remove a task
- Keep using the list or exit, your choice

**Concepts practiced:**
- Functions
- Lists
- `while` loops with `break`
- User input handling

## 2. Expense Tracker (python)
A command-line expense tracker that lets users log expenses, view them, calculate totals, and remove entries — all within a single session.

Features:
- Add an expense (category + amount)
- View all expenses
- View total spent
- Remove an expense
- Exit when done

Concepts practiced:
- Dictionaries for storing category/amount pairs
- Lists for tracking totals
- Functions for modular design
- Input validation (positive amounts, safe removal)
- while loops with break
